Connect your iPhone once and every app you build later — `https://notes.fleet` and beyond — works directly in Safari over Wi-Fi or cellular whenever Tailscale is connected. No Apple Developer account or separate iOS app is required.

## Before you scan

1. Finish the [gateway quickstart](/docs/quickstart), including adding the restricted `fleet` DNS rule in Tailscale.
2. Keep your gateway computer awake.
3. Connect your iPhone to the same Tailscale network and make sure Tailscale DNS settings are enabled.

## 1. Start phone setup on your gateway

Run this on your **gateway** computer (not a secondary checkout computer):

```sh
fleet phone
```

Fleet opens a temporary, private setup page over Tailscale Serve on port **8444** and prints a QR code in your terminal. Scan it and open the link in **Safari**.

<Note>
If Tailscale Serve or HTTPS isn't enabled on your tailnet yet, `fleet phone` prints the exact approval link from Tailscale and waits while you enable it. Fleet never overwrites an existing Serve route on port 8444, and the setup link automatically expires after 15 minutes.
</Note>

## 2. Install and trust your certificate profile

1. Tap **Download profile** on the setup page, then tap **Allow**.
2. Open **Settings → General → VPN & Device Management**, tap **Fleet private apps**, and install the profile.
3. Open **Settings → General → About → Certificate Trust Settings** and enable full trust for **Fleet private apps**.

The profile contains **only** your installation's public root certificate — never your private signing key, and never any MDM or VPN configuration. Because root trust is broad system trust, only install profiles from your own gateway.

Apple's guides cover [installing configuration profiles](https://support.apple.com/en-us/102400) and [enabling manual certificate trust](https://support.apple.com/en-us/102390) if menu names differ slightly on your iOS version.

## 3. Sign in and open your apps

Return to the setup page in Safari and tap **Open Fleet**. That opens `https://gate.fleet/phone`, signs Safari in through Fleet Gate, and automatically turns off the temporary port-8444 setup route.

From there, tap any app (or visit `https://notes.fleet` directly). If you ever need to sign in again later, run `fleet gate` on your gateway and enter the code at `https://gate.fleet`.

If you cancel setup early and want to close the temporary link manually, run:

```sh
fleet phone off
```

## Removing phone trust

If you retire your Fleet installation, remove the **Fleet private apps** profile in **Settings → General → VPN & Device Management**. If no devices use the gateway anymore, also remove the restricted `fleet` DNS rule in Tailscale. See the [security model](/docs/security) for details.
